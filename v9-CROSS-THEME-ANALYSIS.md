## Cross-Theme Connections (v9)

### 1. The Evaluation Stack (☀️ Solar → 🌍 Carbon → 🌊 Ocean)

```
PCMDI (133★) evaluates climate models → WRF (1,763★) simulates atmosphere → MDTF (80★) diagnoses ocean coupling
        ↓                                                                      ↓
   SRM claim validation                                    PBP-POD validates rainfall over ocean
        ↓                                                                      ↓
   "Does SRM cooling show up in observations?"            "Does the model get monsoons right under SRM?"
```

**v9 insight:** The solar geoengineering evaluation stack extends from PCMDI (metrics) through WRF (simulation) to MDTF (ocean diagnostics). But the chain has a gap: MDTF evaluates *current* climate, not *geoengineered* climate. Nobody has built an MDTF module for SRM scenarios.

### 2. The Open-Science Revolution (🌍 Carbon)

```
Open-Sustainable-Technology (2,552★) — The directory
        ↓
   ‖ two movements ‖
   ↓                   ↓
OSHWA (hardware)    CC0 (data)
OpenAir-Cyan          DAC_peroxovanadates
(76★, frozen)         (2★, frozen)
OSHWA US001095        CC0 dedication
Feb 2024              Sep 2025
```

**v9 insight:** Two parallel movements trying to make carbon capture open — OSHWA for hardware, CC0 for data. Neither has merged. Neither has spawned a third wave. The revolution is two-pronged but not yet unified.

### 3. The Governance Deficit (☀️ Solar → 🌊 Ocean)

```
Geo-DICE (2★, dead) — First DICE+SRM model (economics)
        vs.
OOCC_2021 (2★, dead) — First SRM governance model (institutions)
        vs.
Ocean intervention repos (0) — No governance, no science, no tools
```

**v9 insight:** Geo-DICE and OOCC_2021 are both dead, but they represent two different governance questions: "What does it cost?" and "Who decides?" For ocean intervention, there's neither a cost model nor a governance model nor a science model. The governance deficit is total.

### 4. The CC0 → AI Pipeline (🌍 Carbon → All Themes)

```
CC0 license adoption (Sep 2025):
   DAC_peroxovanadates (2★) → public domain screening data
   DAC_peroxotitanates (2★) → public domain screening data
        ↓
claude-carbon entry in Open-Sustainable-Technology (Aug 2023):
   AI tools for carbon-aware compute scheduling
        ↓
AI disclosure in PR template (Jul 2026):
   Every PR must now include AI content checkbox
```

**v9 insight:** The CC0 data movement and the AI governance movement are converging. Public domain data enables AI training. AI training requires governance. Governance requires disclosure. The carbon capture open-source ecosystem is developing a complete pipeline: open data → AI tools → governance → disclosure. This is a model that solar and ocean geoengineering could adopt.

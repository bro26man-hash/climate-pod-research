## 🔥 Headline Findings (September 2026)

### 1. Institutional Bursts Dominate Climate Software
WRF (v4.8.0, 15 commits), PCMDI (v4.2.1, 15 commits in 3 days), MDTF (10 commits) — all funded, all institutional, all reliable.

### 2. The August 2026 DAC Materials Wave
Four repos (peroxovanadates, peroxotitanates) updated on the same day (Aug 19). A coordinated paper event, not a community.

### 3. Ocean Geoengineering is Silent
**8 GitHub searches, 0 repositories.** The ocean is the "dark matter" of climate tech on GitHub.

### 4. Dormancy is the Default
15 of 18 repos show no meaningful activity in the last year. The 85-star ghost project (frozen 5 years) is the archetype.

### 5. The Governance Gap is Staggering
Only 2 governance-related repos exist across all themes — both frozen since 2018 and 2021. Moore's law for climate policy code has not been a thing.

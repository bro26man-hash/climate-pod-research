## 🚨 Headline Finding: The Ocean Intervention Gap

**Our GitHub search across 6 query strategies returned ZERO dedicated ocean geoengineering repositories.** Ocean geoengineering is the "dark matter" of climate tech on GitHub — it exists in the scientific literature but not in open code. This is the most significant finding of the entire research effort.

**See:** [ocean-intervention/OCEAN-GAP-ANALYSIS.md](https://github.com/bro26man-hash/climate-pod-research/blob/ocean-intervention/OCEAN-GAP-ANALYSIS.md)

## 📊 Cross-Theme Commit Trend Summary (September 2026)

### 1. Institutional Bursts Dominate Climate Software
- **PCMDI/pcmdi_metrics:** 15 commits in 3 days for v4.2.1 release (Sep 2-4, 2026)
- **WRF:** v4.8.0 release with 15 commits in ~4 weeks (May-Jun 2026), including solar radiation physics fix
- **MDTF-diagnostics:** 10 commits in 3 months, institutional NOAA-GFDL pattern
- **All institutional, all funded.** Community-driven climate software is the exception.

### 2. The August 2026 DAC Materials Wave
- **Four repositories** (peroxovanadates, peroxotitanates, OpenCarbon, Carbon-Capture-Genome) all updated on **August 19, 2026**
- Suggests a coordinated research event — likely a shared publication or dataset drop
- Small repos (2 stars each) but active — the computational chemistry community is moving fast
- **The ocean didn't participate in this wave.**

### 3. Ocean Geoengineering is Silent
- **Zero repositories found** across 6 search strategies
- The absence itself is a governance and institutional story
- MDTF-diagnostics (precipitation-buoyancy POD) is the closest ocean-adjacent tool
- The gap is systematic: no OAE, no iron fertilization, no MCB, no ocean carbon cycle tools

### 4. Dormancy is the Default
- **yohanesnuwara/climate-capture-and-storage:** 85 stars, zero activity since May 2021 (ghost project)
- **ClimateMARGO:** 2.5 years dormant, then 2 README updates (revival signal?)
- **OpenAir-Cyan:** 15 commits on one day (Feb 2024), then frozen
- **15 of 18 repos** show no meaningful activity in the last year

### 5. The Governance Gap is Staggering
- **Solar:** 3 governance tools (OOCC_2021, Geo-DICE, SRM economics) — all minimal
- **Carbon:** CCS_article (R code for policy feasibility) but dormant
- **Ocean:** Zero governance tools of any kind
- **Physics has outpaced policy infrastructure by a decade**

### 6. Curation Outlives Code
- **awesome-geoengineering:** Updated 5 times in 2026, v2.0.0 in May — healthiest activity pattern
- **Carbon_Capture_ML:** Survey-only but comprehensive — 12 commits in 10 days (Jan 2023)
- The useful tools are surveys and lists, not complex simulations

### 7. Interactive Tools are Emerging
- **orbital-climate-simulator:** Updated Sep 17, 2026 — SRM drone fleet dashboard
- **srm-forever:** Updated Aug 26, 2026 — SRM economics model
- The "democratization" wave is real but still tiny

## The OpenAir-Cyan Phenomenon

**Why this repo matters more than any other:**
- It's the only carbon capture project on GitHub with substantive community engagement (76 stars, OSHWA certification)
- The "code" is documentation: assembly guides, BOMs, wiring diagrams, test results
- It demonstrates that open-source hardware in climate tech follows a different lifecycle than software — burst activity around certification/milestones, then maintenance mode
- The Aug 2024 burst (OSHWA UID, CITATION.cff, file uploads) looks like a "formalization event" — making the project citable and certifiable for academic use

## The August 2026 DAC Materials Wave

Three repos appeared/updated on the same date (Aug 19, 2026):
1. **DAC_peroxovanadates** — peroxovanadate sorbent screening
2. **DAC_peroxotitanates** — peroxotitanate sorbent screening
3. **OpenCarbon** — DAC system planning

**Hypothesis:** This is a coordinated research event — possibly:
- A paper submission deadline (e.g., a special issue on DAC materials)
- A grant deliverable (e.g., a 3-year project coming due)
- A hackathon or collaborative sprint

**What it signals:** The field is moving from "can we capture CO2?" to "what *specific materials* capture CO2 best, and how do we *plan systems* around them?"

## The CCS Failure Dataset

**ProPublica's carbon-capture-cant-solve-climate-change** is a crucial finding:
- 0 stars, but potentially the most impactful carbon capture resource on GitHub
- It provides the data behind ProPublica's 2026 investigation: CCS has consistently underperformed its projections for decades, while solar power has consistently exceeded theirs
- This is the "receipts" — the data that proves the carbon capture industry has been lying about its viability
- **Episode use:** The factual backbone for "Can carbon capture save us? The data says no."

## Biomimicry: Carbonize

**SahilKhutey/Carbonize** represents a genuinely new direction:
- Coral-inspired biomineralization — using nature's own CO2 capture mechanism (coral reefs sequester carbon via CaCO3 formation)
- Multi-pollutant capture: not just CO2, but SO2, NOx, and heavy metals
- SaaS platform, not just a research tool — someone is trying to commercialize this
- **Episode angle:** "Nature has been doing carbon capture for 500 million years. Why are we ignoring it?"

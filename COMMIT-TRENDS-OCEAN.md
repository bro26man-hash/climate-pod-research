## Why This Matters More Than You Think

The absence of ocean geoengineering code is **not a neutral fact** — it's an **active signal** about where climate innovation is happening:

1. **Funding follows code.** The NSF, DOE, and DARPA fund projects that produce publications, which produce repositories. Zero repos = zero funded ocean geoengineering computation projects.

2. **Governance follows code.** The London Protocol doesn't prohibit ocean geoengineering because someone wrote a checker — it's a policy choice. But if someone builds a governance compliance tool, it could change the conversation.

3. **Community follows code.** The open-source climate community is small and specific. If ocean intervention never enters this community's consciousness, it stays in the academic journal silo forever.

4. **Public understanding follows code.** You can't reason about what you can't inspect. Open-source code is how the public learns how these technologies would work. No code = no public understanding = no democratic input.

## The "If You Build It" Hypothesis

What if the ocean gap is best addressed by **building the first repo?**

### The 1,000th Repo Problem
Climate tech GitHub is dominated by renewables and efficiency. The top repos are:
- Solar PV modeling
- Wind farm optimization
- Battery chemistry
- Electric vehicle infrastructure
- Carbon accounting

Ocean geoengineering would be the **1,000th niche** — too small for institutional funding, too risky for academic careers, too complex for hobbyists. But it's also the most **high-leverage** missing piece: because it's absent, the first repo gets all the attention.

### The "Good Enough" Strategy
The first ocean geoengineering repo doesn't need to be perfect:
1. **A dataset** — even one small experiment (LOHAFEX data) organized as a clean CSV
2. **A parameterization** — a simple Python module for ocean alkalinity enhancement chemistry
3. **A governance checker** — a London Protocol compliance document with code

Any one of these would be the **first** in its category. First-mover advantage in ocean geoengineering code is enormous because the field is so empty.

# 🌊 Ocean Intervention Episode — Research Notes

## Theme Overview
Ocean geoengineering is the empty quadrant. Across six search strategies, we found **zero** open-source repositories for ocean alkalinity enhancement, iron fertilization, marine cloud brightening, or any ocean-based climate intervention. This is not a search failure — it's the defining finding of this research.

## The Gap

| Ocean Intervention Type | GitHub Repos | Active Repos | Stars |
|------------------------|-------------|-------------|-------|
| Ocean Alkalinity Enhancement (OAE) | 0 | 0 | 0 |
| Iron Fertilization | 0 | 0 | 0 |
| Marine Cloud Brightening (MCB) | 0 | 0 | 0 |
| Seaweed/Algae Farming | 0 | 0 | 0 |
| Ocean Carbon Cycle Manipulation | 0 | 0 | 0 |
| **Total** | **0** | **0** | **0** |

## The Closest We Got

**NOAA-GFDL/MDTF-diagnostics** (80 ⭐) — includes a precipitation-buoyancy statistics POD added in June 2026. This is the only climate code that touches ocean processes with active development, but it's a diagnostic tool, not an intervention simulator.

## Hypotheses for the Gap

1. **Residency time mismatch** — Ocean interventions operate on decadal scales; academic papers need faster results
2. **Governance vacuum** — No policy framework, no funding calls, no standards
3. **Monitoring impossibility** — No sensor infrastructure to verify ocean interventions
4. **Computational cost** — Eddy-resolving ocean models are 10-100× more expensive than atmospheric models
5. **Ethical risk aversion** — Researchers self-censor code that could enable harmful marine interventions

## 🎙️ Podcast Angles

- "We searched six different ways and found nothing. The ocean is the silent quadrant of climate tech on GitHub."
- "The code gap is a governance gap. No policy, no funding, no standards — and the code reflects it."
- "We can evaluate ocean processes in climate models (MDTF), but we can't simulate ocean interventions. That's the gap."
- "If the podcast catalyzes the first open-source OAE simulator, we'd be making history."

## The Pattern of Absence

### Why Zero Repos Matters More Than Zero Stars

The absence of ocean geoengineering code is **not a bug** — it's a feature of the governance and research landscape:

1. **London Protocol restrictions** — Ocean fertilization and OAE are regulated. Researchers face legal barriers to publicly sharing deployment-relevant information.

2. **CBD moratorium** — The Convention on Biological Diversity has called for a moratorium on ocean fertilization. This chilled open-source development.

3. **Selective invisibility** — Some ocean geoengineering researchers deliberately avoid open-source repos to prevent their work from being interpreted as "deployment stories."

4. **The academic incentive structure** — Ocean geoengineering faces different incentives than atmospheric science. Research at sea is dangerous, expensive, and politically sensitive. The "do-no-harm" norm is dominant. The unspoken norm is: don't share code that could be used for deployment.

5. **No instrumented platforms** — Unlike atmospheric monitoring (which has generous academic funding for sensor networks and data), there are very few ocean geoengineering test beds to instrument and write code about.

## Ethical / Governance Considerations for the Episode

1. **The "Don't Build the Match" Argument**
   - Proponents of ocean geoengineering openly argue that some science is so dangerous it shouldn't be published
   - Ocean sciences have stronger "do-no-harm" norms than atmospheric science
   - Contrast with solar geoengineering where the physics is considered relatively "safe" to model

2. **Democratic Deficit vs. Democratic Safety**
   - Solar geoengineering: Too much code in too few hands = democratic deficit
   - Ocean intervention: Too little code anywhere = democratic safety but also democratic deficit

3. **The "Stealth" Problem**
   - With no open-source code, how can the public evaluate ocean interventions before they are deployed?
   - The governance vacuum: We can't govern what we can't see

4. **The Curious Impact of the Absence**
   - The lack of code means there's no way for developing nations to scrutinize ocean intervention proposals
   - The governance void is asymmetric: rich-nation researchers can publish papers, but open code isn't there
   - This creates a knowledge economy where only the funded few can participate in the debate

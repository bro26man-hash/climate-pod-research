# 🌊 Episode Plan — Ocean Intervention

## Working Title
"The Empty Ocean: Why Geoengineering's Biggest Quadrant Has No Code"

## Episode Arc

### Act 1: The Search
- We searched GitHub for ocean geoengineering and found nothing. Zero repos. Zero code.
- But the scientific literature is full of ocean intervention proposals.
- Where did all the code go?

### Act 2: The Governance Story
- London Protocol, CBD moratorium, and the "don't build the match" argument
- Ocean geoengineering is the most geopolitically sensitive climate tech
- The chilling effect: Governance has prevented code from existing
- But is that good or bad?

### Act 3: What If It Were Open?
- Designing a hypothetical OAE simulation tool — what would it include?
- Seaweed/kelp cultivation: the least regulated, most likely to go open-source
- The "detection problem" — ocean intervention happens below the surface, harder to monitor
- The democratic question: Can we govern what we can't see?

## Key Segments
1. **"The Search"** — The actual GitHub search results, the shock of the empty dataset
2. **"The Don't-Build-the-Match Argument"** — The ethics of publishing dangerous knowledge
3. **"Governing the Invisible"** — How the London Protocol and CBD shaped the code landscape
4. **"Seaweed as the Exception"** — Kelp cultivation vs. OAE vs. iron fertilization
5. **"What Would OAE Code Do?"** — Hypothetical: an open-source ocean alkalinity simulation

## Production Notes
- **Duration estimate:** 35-50 minutes
- **Tone:** Exploratory, philosophical, with a hard pivot to practical governance questions
- **Caveat:** Be balanced. Don't dismiss the governance concerns as censorship, but don't romanticize the absence either. The "dark matter" metaphor should feel weighty — not triumphant.
- **Music suggestion:** Deep, underwater ambient for ocean segments. Has a mysterious quality that matches the theme.

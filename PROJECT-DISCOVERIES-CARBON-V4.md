## 🔍 Cross-Cutting Themes from Commit Analysis

### 1. The CC0 Revolution
The most important trend in carbon capture open-source isn't a code change — it's a license change. tjz21's two DAC materials repos both adopted CC0 in September 2025. This represents a philosophical shift: **computational screening data should be treated as public infrastructure, not private property.**

If this pattern spreads, it could transform how DAC materials research works. Today, most materials data is trapped in paywalled journals or proprietary databases. CC0 says: the data is the science, and the science belongs to everyone.

### 2. The OSHWA Certification Moment
OpenAir-Cyan's February 2024 commit day — 7 commits including OSHWA certification — is a landmark. It's the first (and maybe only) open-source DAC device that meets hardware certification standards. But the subsequent 2+ year freeze raises a question: **is certification the finish line, or the starting line?**

### 3. The Directory vs. The Lab
The carbon capture ecosystem has a structural imbalance:
- **2,552 stars** for a directory (open-sustainable-technology)
- **76 stars** for a working DAC device (openair-cyan)
- **2 stars** for computational screening code (tjz21's repos)
- **85 stars** for a dead MATLAB repo (citation magnet)

The directory gets more attention than the hardware. The hardware gets more attention than the code. The code gets less attention than nothing. This tells us something about where climate tech investment flows — and where it doesn't.

### 4. The Crypto Infiltration
Multiple carbon capture repos are actually crypto projects (CarbonCapture smart contract, CarbonVault token protocol, CarbonNeg synthetic). These aren't building capture technology — they're building financial instruments around it. This is a governance question: does tokenizing DAC accelerate or obscure real climate action?

### 5. The Living Literature Problem
Carbon_Capture_ML shows the "living literature review" pattern: start strong, catalogs papers furiously, then slow down as the field matures or the author moves on. The risk: when a literature review goes stale, it becomes a liability — people cite it, but the citations become outdated.

# ☀️ Solar Geoengineering Episode — Research Notes

## Theme Overview
Solar geoengineering (SRM) research on GitHub focuses on atmospheric simulation, radiative forcing modeling, and — surprisingly — governance tools. The commit history reveals a stark divide: institutional climate models are vigorously maintained, while SRM-specific tools are born and die with publication cycles.

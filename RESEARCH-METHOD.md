# 🔬 Research Methodology

## Search Strategy
1. GitHub repository search using diverse queries:
   - `geoengineering simulation climate`
   - `climate tech open source`
   - `solar radiation management geoengineering`
   - `climate simulation earth system model`
   - `carbon capture direct air DAC`
   - `ocean iron fertilization albedo`
   - `geoengineering radiative forcing`

2. Commit history extraction from top match repos spanning all three themes
3. Cross-referencing: umbrella directories (open-sustainable-technology) used as discovery layers

## Repos Investigated
- 6 repositories received full commit history analysis
- 10+ repositories received high-level review
- 3 theme branches created for organized episode notes

## Branch Naming Convention
- `solar-geoengineering` — SRM, albedo modification, radiative forcing
- `carbon-capture` — DAC, BECCS, enhanced weathering, sorbent materials
- `ocean-intervention` — OAE, iron fertilization, seaweed, upwelling manipulation

## Content per Branch
- `research-notes.md` — structured project discoveries, commit trends, talking points
- `episode-outline.md` — segment-level podcast episode plan

## Key Insights
- **Solar:** Legacy Fortran + emerging Jupyter; open-source simulation gap
- **Carbon:** Two modes (materials vs. systems); DAC materials surge in Aug 2026
- **Ocean:** The biggest gap; governance/complexity barriers to open-source

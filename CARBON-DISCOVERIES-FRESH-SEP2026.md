## Key Topics

**Burst-and-Freeze:** Every capture repo follows the same lifecycle — creation, burst, peak, silence, dormancy. Only the directory survives because curation is networked labor.

**Why They Can't Sustain:** Hardware gap, expertise bottleneck, academic incentives, corporate displacement, funding vacuum.
